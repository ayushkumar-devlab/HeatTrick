# Optional hero photos

Add royalty-free photos named `plains`, `plateau`, `coastal`, `arid`, `hills`, or `default` with a `.webp`, `.jpg`, `.jpeg`, or `.png` extension. Use landscape images around 1600 × 900 pixels; WebP under 250 KB is recommended.

Only add photos you have permission to use. Confirm that the licence allows redistribution with the app, and record attribution in `credits.json` when required. Photos are decorative and fall back to the original SVG landscape when no matching file exists.
