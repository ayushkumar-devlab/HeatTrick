# HeatTrick

HeatTrick is an academic research platform for localized heatwave early warning and human thermal stress risk assessment in India.

## Tech Stack
- **Frontend**: React, Vite, TypeScript, Tailwind CSS, Lucide React
- **Backend**: Python 3.10, FastAPI, Uvicorn, Pydantic
- **Version Control**: Git

## Current Status
- **Milestone 0**: Frontend-Backend Foundation Setup
